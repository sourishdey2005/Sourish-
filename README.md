# Sourish Dey — Professional Portfolio

High-performance, enterprise-grade engineering portfolio for Sourish Dey — a Data Scientist, ML Engineer, and Computer Science Researcher specializing in quantitative finance engines, AI architectures, and distributed systems.

**Live site:** https://sourishdeyportfolio.vercel.app/

## Tech Stack

- **Framework:** React 19 + TypeScript
- **Build tool:** Vite 6
- **Styling:** Tailwind CSS (via CDN) + custom CSS
- **Animation:** Framer Motion
- **3D / Charts:** React Three Fiber, Recharts
- **Linting:** ESLint 9

## Getting Started

### Prerequisites

- Node.js 18+ (or Bun)
- npm (or bun)

### Install

```bash
npm install
```

### Development

```bash
npm run dev
```

Opens the dev server (default http://localhost:5173).

### Production Build

```bash
npm run build
```

Output is written to `dist/`.

### Preview Production Build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```

## Project Structure

```
.
├── App.tsx            # Main application component
├── components/        # Reusable UI components
├── constants.ts       # Portfolio data (experience, projects, publications, etc.)
├── types.ts           # TypeScript type definitions
├── index.html         # HTML entry point
├── index.tsx          # React entry point
├── index.css          # Global styles
├── navigationTabs.ts  # Navigation tab definitions
├── vercel.json        # Vercel deployment config
└── vite.config.ts     # Vite configuration
```

## Deployment

The site is deployed on Vercel. Pushing to `main` triggers an automatic deployment. Configuration lives in `vercel.json`.
